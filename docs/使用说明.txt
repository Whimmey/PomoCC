番茄钟监督 —— 使用说明
========================================

这是什么
  一个番茄钟。不同的是：它盯着你。
  规定时间里没坚持完专注，或者某个程序超过它自己的规则时长，
  它会自己给你的监督人发一封邮件，把细节写清楚。

怎么开始（三步）
  第 1 步：双击「PomoCC-番茄钟监督.exe」
      第一次运行会让你设一个密码。这个密码是「退出」和「改设置」用的。
      设了它，你自己心烦时就没办法顺手把程序关掉。

  第 2 步：点「设置」，左侧有三页，先做前两页

      【监督名单】点「＋ 添加程序」
         窗口里会列出你电脑上正在运行的程序，带图标和真实名字，
         可以用上面的搜索框过滤，按住 Ctrl 可以多选，双击直接添加。
         程序没开着就点「从 exe 文件选…」。加进来之后是一张表：

           名称          软件                规则时长（分钟）   操作
           奶龙          game · game.exe           1            删除
           Steam         Steam · steam.exe         3            删除

         · 「软件」列是程序自己报的名字 + 进程名，只读，用来认人。
         · 「名称」列默认和「软件」列一样，双击就能改。
           很多程序自报的名字只是 game 这种代称，把它改成「奶龙」，
           告状邮件里就会写「奶龙（game.exe）」，监督人一看就懂。
         · 「规则时长」= 专注期间这个程序允许累计跑多少分钟。
         · 不想要的点那行的「删除」，或选中后点「删除选中」。

      【邮件设置】
         监督人邮箱 —— 告状邮件发给谁
         你的发件邮箱 —— 用你自己的邮箱发（比如 12345@qq.com）
         授权码 —— 注意！不是邮箱登录密码，见下面「怎么拿授权码」
         填完先点「测试连接」确认能连上服务器，
         再点「发送测试邮件」确认能收到。

       【内容自定义】（同一页往下滚）
         这里有三段是你自己的话，会加进告状邮件：
           邮件标题  —— 默认「【专注监督】{日期} {时刻} · {简述}」
           开头      —— 默认「{名字} 的这一次专注没有达标。」
           结尾/落款 —— 默认「本邮件由该电脑上的『番茄钟监督』程序自动发送…」
         花括号里的是占位符，发送时会换成真实数据：{名字}、{时间}、{日期}、
         {时刻}、{原因}、{简述}、{计划专注}、{实际专注}、{监督人}。
         下面表格里绿色那三个（{程序明细}、{今日累计}、{时间线}）也随时能用。
         点「预览效果」看拼出来是什么样，「恢复默认内容」一键回到默认文案。

       ★ 放心：邮件中间那块「监督名单程序在本次专注期间的运行情况」
         （含每个软件的累计使用时长、启动时间、时间线、今日累计）是程序
         固定插入的，不来自上面三段自定义内容 —— 你怎么改都不会把它弄丢。

      点「保存」后**窗口不会关闭**，左下角只显示「已保存」，改动立即生效 ——
      你可以继续翻其它页、继续改。要离开设置时点「关闭」（或右上角 ✕）。

  第 3 步：点「开始专注」
      圆环开始走，它就开始盯着了。

专注走完时会提醒你
  走完那一下会弹一个托盘气泡 + 响一声（用你系统的提示音）。
  不想要就在「设置 → 规则与其他 → 专注完成时」把两个勾去掉（默认都开着）。
  记住：正常完成不会给监督人发邮件，这一步只是提醒你自己该休息了。

想看看正在监视哪些程序
  待机或专注时，主界面那行「正在监视 N 个程序」里的「程序」是蓝色下划线的，
  点一下就会弹出清单（名称 / 软件 / 规则时长），和「监督名单」一样，
  但没有「操作」列 —— 这里只是看，不会误改。要改请去「设置 → 监督名单」。

想改专注时长
  双击中间的大号时间（比如 25:00），会变成可编辑：
  「专注时长 [25 ▼] 分钟」——下拉框里是常用值（10/15/20/25/30/45/60/90/120），
  也可以直接填任意数字，按回车或点「确定」保存，Esc 或「取消」放弃。
  改完立刻生效并记进配置，下次打开还是这个时长。
  正在专注中不让改（会提示先等这一段结束）。

它什么时候告状（只有两种情况）
  · 你没坚持完：计时没走完就点了「放弃」→ 立刻发邮件
  · 某个程序超时：专注期间它的累计运行时间超过它自己的规则时长 → 立刻发邮件
  正常走完 25 分钟，它一句话都不会说。
  一段专注最多发一封，不会刷屏。

邮件里写了什么
  哪天几点、因为什么、计划专注多久 / 实际专注多久、
  是哪个程序（用你起的名称 + 进程名）、这次跑了多久、它的规则是多少分钟、
  什么时候启动的、完整时间线。

怎么拿授权码
  QQ 邮箱：网页版邮箱 → 设置 → 账户 → 找到「POP3/IMAP/SMTP 服务」→
           开启「IMAP/SMTP 服务」→ 按提示验证 → 得到一串 16 位授权码。
           服务器填 smtp.qq.com，端口 587，勾选「使用 STARTTLS」。
  163 邮箱：设置 → POP3/SMTP/IMAP → 开启 SMTP 服务 → 得到授权码。
           服务器填 smtp.163.com，端口 465，
           并把「使用 STARTTLS」取消勾选（程序会自动改用 SSL）。
  Gmail：  要先开启两步验证，再生成「应用专用密码」。
           服务器填 smtp.gmail.com，端口 587，勾选 STARTTLS。
  其他邮箱：搜「<你的邮箱> SMTP 服务器 端口 授权码」就能找到。

想用邮件接口而不是授权码
  「发送方式」还能选 SendGrid（免费 100 封/天）或 Brevo（免费 300 封/天），
  注册后验证一个发件邮箱即可，不用买域名。
  Resend 的免费额度需要先绑定自己的域名才能发给别人，一般不建议。

【规则与其他】页里的开关
  · 专注时长：默认 25 分钟。
  · 新程序默认规则时长：新加进来的程序先用这个值，之后可以在表格里逐个改。
  · 检测间隔：默认 5 秒扫一次，一般不用改。
  · 只统计「专注开始之后」才启动的程序：默认关。
    关着的时候：专注期间只要名单里的程序开着，就算在玩。
    打开之后：专注前就已经开着的程序不计入（比如后台挂着的下载器）。
  · 开机自动启动 / 点关闭按钮时缩到托盘：默认都开。
    想真正退出：右键右下角托盘图标 →「退出」→ 输密码。
  · 修改密码 / 打开数据文件夹。

界面清晰度
  程序已适配高 DPI 缩放（125% / 150% 这类设置），文字不会被系统拉伸模糊。
  如果你在系统里改了缩放比例，重启一下本程序即可按新比例重新排版。
  窗口可以自由拉伸，卡片高度会跟着内容自动调整，不会有按钮被挡住。

数据存在哪里
  C:\Users\<你的用户名>\AppData\Roaming\PomoCC\
      config.json     设置（授权码和 API Key 都是加密存的）
      history.jsonl   历次告状邮件全文
      stats.json      今日统计
      app.log         运行日志
  在设置里点「打开数据文件夹」可以直接打开它。

必须说清楚的限制
  · 它防不住铁了心的你：任务管理器结束进程、禁用开机自启、把授权码改错，
    都能让它发不出邮件。它的作用是「让关掉它变得麻烦」，不是不可破解。
  · 程序关着就不监督。所以默认开了开机自启 + 托盘常驻。
  · 电脑睡眠期间不计时：睡过去不算你完成专注，也不会因此告状。
  · 授权码等于你邮箱的发信权，别把 config.json 发给别人。
  · 忘了密码只能删掉 config.json 重来（设置会一起丢）。
  · 监督名单匹配的是「进程名」；用「添加程序」按钮就不用手敲了。

出问题了怎么办
  · 连不上服务器：点「测试连接」，它会说清楚卡在哪一步。
  · 收不到邮件：让监督人翻一下垃圾邮件箱，或加到白名单。
  · 想补发：点「告状记录」，选中那条，点「重发选中」直接补发一次
    （原记录保留，重发结果会另记一条）。没有配置邮箱时，
    也可以「复制全文」自己手动发。
  · 想看细节：打开数据文件夹里的 app.log。
  · 状态列写着「未确认（可能未发出）」：那是旧版本留下的记录 ——
    当时程序在邮件发完之前就退出了。点「重发选中」补发即可。
    新版本不会再产生这种记录（只有拿到发送结果后才写记录），
    而且正常退出时程序会先等在途邮件发完。

想知道版本号 / 找作者
  打开「设置」，左下角就有「PomoCC 版本号」和作者链接，点作者会打开 GitHub 仓库。
  主窗口和设置窗口的标题栏上也带着版本号。

提示：dist 目录里的「PomoCC-番茄钟监督.exe.config」要跟 exe 放在一起，别单独删掉。
